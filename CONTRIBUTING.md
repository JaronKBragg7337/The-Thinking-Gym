# Contributing

The Thinking Gym welcomes proposed exercises, refinements, session formats, calibration methods, and documented sessions.

## Contribution standard

A contribution should improve the practice of reasoning rather than promote a predetermined conclusion.

Exercise proposals should include:

- the cognitive capability being trained;
- clear rules;
- a repeatable procedure;
- common failure modes;
- a completion standard; and
- an explanation of how the exercise differs from existing ones.

## Session contributions

Session records should:

- preserve the starting position before substantial revision;
- represent opposing arguments fairly;
- distinguish fact, inference, and speculation;
- retain uncertainty and disagreement;
- include confidence estimates where applicable;
- avoid retroactively rewriting predictions; and
- end with **What changed?**

## Conduct

Critique ideas directly without degrading participants. Good-faith disagreement is expected. Straw-manning, harassment, fabricated evidence, and performative certainty undermine the project.

## File conventions

- Exercise definitions: `exercises/kebab-case-name.md`
- Session records: `sessions/NNNN-exercise-topic.md`
- Program versions: `versions/vN-name.md`
- Principles and methods: descriptive Markdown files in `principles/` or `metrics/`

## Proposed changes

Use a focused pull request with a clear explanation of:

1. what changes;
2. why it improves the Gym;
3. how it was tested or reasoned through; and
4. any tradeoffs or unresolved concerns.
