# Future Headlines

## Purpose

Practice forecasting by turning expectations into specific, dated, falsifiable predictions that can later be scored against reality.

## Core method

Write plausible future headlines for a defined time horizon. For each prediction, record its probability, causal reasoning, assumptions, and disconfirming conditions.

## Rules

1. Set an explicit prediction date or window.
2. Make each headline specific enough to be judged later.
3. Assign a probability rather than using vague confidence language.
4. Record the causal chain and critical dependencies.
5. Include at least one prediction that challenges personal preference or expectation.
6. Do not rewrite predictions after outcomes become known; add a dated update instead.
7. Score results for both outcome accuracy and confidence calibration.

## Completion standard

The artifact contains falsifiable forecasts, probabilities, reasoning, resolution criteria, and a scheduled review date.
