# Break the Invention

## Purpose

Stress-test an idea before reality does. This exercise trains adversarial design, failure analysis, risk discovery, and resilience.

## Core method

Present an invention, system, product, policy, or project. Attack it from technical, human, economic, operational, legal, environmental, and misuse perspectives. Then determine which failures are fatal, which are repairable, and which reveal a better design.

## Rules

1. Define the intended function and success criteria.
2. Identify dependencies and assumptions.
3. Test normal use, edge cases, misuse, neglect, scaling, and hostile conditions.
4. Separate catastrophic failures from tolerable defects.
5. Do not stop at criticism; convert important failures into design requirements.
6. Preserve the original goal even when the implementation must change.

## Completion standard

The artifact contains a ranked failure map, proposed mitigations, and a judgment on whether the idea should proceed, change direction, or be abandoned.
